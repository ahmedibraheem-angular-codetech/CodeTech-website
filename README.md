# CodeTech Website — Angular 21 

A starter implementation for the CodeTech corporate marketing website. The project uses Angular standalone components,  SCSS

## Current scope

- Angular 21 setup
- Responsive header, navigation, footer, and a designed home page
- Starter pages for About, Services, Products, Case Studies, Blog, Contact, FAQ, Privacy Policy, and Terms
- Typed mock models and feature data-access services
- Contact form with validation and a mock submission response
- `@ngx-translate/core` v18 configured with a static in-memory loader

## Requirements

- Node.js 22+
- npm 10+


## Install and run

```bash
npm install
npm start
```

Open `http://localhost:4200` 

## Libraries

- Angular 21 for pages, routing, forms, and standalone components
- TypeScript for typed components and data models
- Bootstrap 5 for responsive layout
- Swiper for carousels
- ngx-translate for Arabic and English interface text
- RxJS for asynchronous updates


## Project layout
- `src/app/core/`: header, footer, layout, and language handling
- `src/app/shared/`: reusable UI components
- `src/app/features/`: pages for home, about, services, products, projects, blog, contact, and legal content
- `public/i18n/`: Arabic and English text for static interface labels
